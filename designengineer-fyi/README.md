# Shai Krishna — designengineer.fyi (study clone)

A local reconstruction of [designengineer.fyi](https://www.designengineer.fyi) for learning and study. The original design, copy, imagery, and fonts belong to Shai Krishna.

```bash
npm install
npm run dev
```

The site runs at http://localhost:3400. Drag the slider or scroll to move through the projects. Contact sits at the top left.
